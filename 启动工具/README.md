# 启动工具

日常看结果可直接双击项目根目录的 [打开项目演示.cmd](../打开项目演示.cmd)。这里集中放置配置和开发过程中使用的入口；从任意工作目录打开都会先定位到项目根目录。

| 文件 | 用途 | 是否调用模型 |
| --- | --- | --- |
| [启动人工标注.cmd](./启动人工标注.cmd) | 匿名初标与初始快照，8501 | 否；保存会记录人工修改 |
| [启动开发集分歧查看.cmd](./启动开发集分歧查看.cmd) | 开发集初标/V1只读对照，8502 | 否 |
| [启动保留集复核.cmd](./启动保留集复核.cmd) | 冻结初标/V1/V2与独立作者复核，8503 | 否；确认保存会追加复核历史 |
| [配置接口.cmd](./配置接口.cmd) | 地址、模型与本次Key设置窗口 | 点击连接/多图测试时会调用 |
| [启动开发集V1.cmd](./启动开发集V1.cmd) | 完整开发集V1密码窗口 | 点击开始后可能调用；仅看结果无需运行 |
| [启动三图联调.cmd](./启动三图联调.cmd) | 历史D04三张样本的密码窗口 | 点击开始后可能调用；已有结果优先复用 |

使用步骤、数据要求与故障排查见 [项目README](../README.md)，全部文档见 [文档导航](../docs/README.md)。Key不写入配置文件。已有实验和失败记录保留，无需为浏览重跑评测。
