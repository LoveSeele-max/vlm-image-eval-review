# VLM 辅助生图评测与人工复核工具

VLM-assisted image evaluation and human review workflow with structured criteria, batch processing, and prompt comparison.

## 当前状态

项目处于实施初期，已完成 **A01-A03**，总进度 **3/32（9.38%）**。工作目录、固定参考图以及 48 个候选文件的原始提示词和来源已经核对；尚未实现 VLM 调用、人工复核页面或对照实验，不提供尚未验证的运行命令和效果指标。

计划基于已有 FLUX 生成图，按主体关键特征、结构完整性和提示词符合度进行逐项评测，保留人工初始标签、模型输出和分歧复核证据。V1/V2 将使用固定标准和同一保留集进行比较。

```text

docs(A02): 固定参考照片并记录选择依据
feat(D02): 实现多图调用与结构化校验
```
