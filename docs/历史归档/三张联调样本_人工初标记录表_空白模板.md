## 怎么填写

1. 对照两张参考图，逐张查看候选图，按下方条目及附录边界判断；点击条目名可跳至边界说明。
2. 在“结果”填写一个中文状态：**符合 / 不符 / 不可判断**，分别对应 `pass / fail / unjudgeable`。不要写“不适用”。
3. “检查部位”已预填，请按实际观察确认或修改；“实际观察”写看到了什么，“判断原因”写它如何支持该条规则，一句短话即可。
4. 每行四项填写完后，把“完成”列的 `□` 改为 `☑`。辅助项同样要填写；看不清用不可判断，并说明遮挡、裁切或模糊等原因。
5. 不评价木桌，不填写总分或整体通过结论。整体结论待程序按固定规则计算。完成一张后再勾选其完成清单。
6. 初标时不参考 VLM 输出或生成配置。作者此前见过这些历史图，这份匿名记录用于减少配置提示，不能称为严格盲评。
7. 可以分次保存。Markdown 保存不等于标签已冻结；填写后还需检查完整性并导入正式记录。

## 判定边界附录

下面直接摘自正式规则。属性组合需全部满足才符合；任一属性有明确矛盾即不符；没有矛盾但证据不全则不可判断。头顶长耳与脸侧小耳并存是允许的设计，正常透视、玩具关节或比例不自动视为结构异常。

| 不可判断 | 彩色强光、过曝、遮挡或模糊使肤色无法可靠辨认。 |

补充边界：允许光照与轻微肤色差异，不推断族群或使用肤色精确 RGB 阈值。

### 大动漫眼睛

条目 ID：`large_anime_eyes`｜必需

| 判断 | 边界 |
| --- | --- |
| 符合 | 可见眼睛相对面部明显偏大，具有动漫式轮廓或简化表现。 |
| 不符 | 眼部清楚却为明显细小的写实比例或其他明确不同形态，或完整可见眼部明确缺失。 |
| 不可判断 | 眼部被遮挡、背向镜头、过小或模糊，不能核对大小与风格。 |

补充边界：不要求与参考相同眼色、视线或高光形状，不固定未经验证的尺寸比例。
