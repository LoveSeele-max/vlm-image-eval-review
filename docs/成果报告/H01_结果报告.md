# H01：VLM 辅助生图评测实验结果报告

> 目录整理说明：本文件已归类；文中的命令和未特别说明的相对数据路径仍以项目根目录为起点。当前入口见 [文档导航](../README.md)，历史阶段状态以记录时点为准。

完成日期：2026-11-09｜实验范围：单一手办主体、40 张历史 FLUX 对照图｜主要参考：冻结 `human_reference_v1`。

## 主要发现

没有观察到 V2 的明确质量提升。总体条件一致率 V1 为 436/453 = 96.25%，V2 为 392/407 = 96.31%；与此同时，决策覆盖率从 453/517 = 87.62% 降至 407/517 = 78.72%，下降约 8.90 个百分点。两版与人工均可判断的同一 388 项中，V1/V2 判断完全相同，一致数均为 374。不同覆盖范围上的小幅百分比变化不能当作准确性提升。

项目完成的是可追溯的评测与人工复核流程：固定输入和规则、人工参考冻结、VLM 多图批处理、逐项校验、失败/缓存/恢复记录、版本对照、作者修订与案例。它没有验证自动审核替代率、人工提效或 LoRA 训练效果。

## 方法与可比较范围

先用开发集 V1 的 14 项状态分歧形成六类解释性修改，再冻结 V2。修改涉及面部标记、发型、底座、背部草帽、脸侧小耳及肢体连接的证据说明；没有改变通过标准、必需性、样本、参考照片、Schema 或聚合顺序。保留集结果没有用于继续调整 V2。

两版串行调用同一中转 Responses 接口，请求/返回的模型标识为 `gpt-6.1-terra`，实际后端身份未独立验证。图片顺序固定为主参考、补充参考、候选；参考整图长边最多 2048、候选最多 512，不裁切、不放大补细节，申请 high detail；服务端实际分辨率处理未独立验证。`max_output_tokens=8192`、超时 180 秒、非流式、`store=false`，每任务最多 3 次尝试。请求次数上限与人民币费用上限是不同约束。

结果先验证严格 JSON 与固定条目：拒绝重复键、非法枚举、样本错配、漏项/重复/未知条目及不完整证据。工程失败优先保留为缺失，不生成视觉 fail。完整结果中，必需项任一 fail 则候选失败；否则必需项有不可判断则待复核，全部符合才通过；辅助项完整记录但不单独否决。本文主要指标按条目统计，不把工程成功数作为图像质量通过数。

## 主要指标及分母

- 决策覆盖率：人工 pass/fail 中，模型也为 pass/fail 的条目数 / 全部人工 pass/fail 数。
- 条件一致率：双方为 pass/fail 且相同的数量 / 双方均为 pass/fail 数。
- 错误通过比例：人工 fail、模型 pass 数 / 全部人工 fail 数。
- 错误拒绝比例：人工 pass、模型 fail 数 / 全部人工 pass 数。

以上错误名称表示相对冻结作者参考的差异，不等于客观真值。工程缺失和模型不可判断不进入二元错误分子，但仍保留在对应人工分母中；因此错误比例下降必须结合覆盖率。零分母写不可计算，JSON 为 null。

## 适用范围、未完成项与下一步

本项目支持固定单一主体的小规模评测辅助流程，提供可检查的自动证据并安排人工处理分歧。数据只有 4 个 seed 家族，主体及提示词模板共享，同图条目相关，720/1080 条记录不等于独立样本数；不报告显著性、通用身份一致性或跨主体泛化。不能据结果说明 LoRA 已学会主体，也不能分离提示词与 LoRA 的训练收益。

未执行同图重复性实验、第二个视觉模型、多人独立复核、局部裁切工具或审核提效对照；不能声称节省人工时间。实际历史生成环境、权重哈希、后端模型身份及服务商人民币账单仍未独立核实。未强制把所有不可判断改成二元标签，也没有把 G03 写成全部 540 项复核完成。

后续建议先补充独立复核和更多主体/负例，再预登记新实验；局部放大、第二模型和重复性可作为新版本。当前完成结论不取决于这些扩展，也不将建议写成已实现能力。
