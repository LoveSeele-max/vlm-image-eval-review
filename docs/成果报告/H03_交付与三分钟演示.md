## 演示前准备

1. 双击 `打开项目演示.cmd`，打开本机汇总页。演示入口不发送模型请求。
2. 如需实时页面，先启动 `启动工具/启动保留集复核.cmd`；核验可能耗时，提前完成。切换“处理状态”为“已明确处理”，再按样本筛选，否则默认“待复核”现在为 0 项。
3. 预开 G04 案例 1（sample_004）及案例 2（sample_017），再预开 H01 或汇总页的指标表。
4. 原图和私有包缺失时，不演示空页面为成功。可使用已核验的本机离线案例/截图，明确标注是保存的证据。
5. 现场不点击保存、重新评测或重试正式失败；已有确认和主要指标保持原样。

## 隔离本地回放：缓存、重试、恢复与拒收

在项目根目录打开 PowerShell：

```powershell
Set-Location image-eval-review/tests
python -m unittest -v `
  test_run_tasks.RunTests.test_verified_cache_reused_with_no_key_no_attempt_and_no_budget_charge `
  test_run_tasks.RunTests.test_429_retried_and_each_attempt_retains_independent_response `
  test_run_tasks.RunTests.test_interrupt_before_network_releases_unsent_reservation_and_can_resume `
  test_run_tasks.RunTests.test_invalid_json_result_gets_bounded_retry
Set-Location ../..
```

这4项复用已有测试，在临时目录和 `127.0.0.1` 模拟服务中运行，使用合成输入及假测试凭据；不会触碰正式库，也不需要真实 Key。它们依次验证：成功证据核验复用且不增加尝试/名额；429后成功且两次原始响应均保存；发送前中断恢复并继续；非法JSON不进入成功并在上限内重试。H03 已实际执行通过，原正式计数仍70/100。

若现场只需三分钟，直接展示本机 `h03_replay.json` 与保存的测试输出；不要等待付费接口或把回放当真实模型新表现。真实响应隔离副本的恢复/拒收验证另见 [D04](../阶段记录/D04_三图联调记录.md)。
