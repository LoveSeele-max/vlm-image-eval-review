## 使用方法

在项目根目录运行；默认输出到 `private/annotation_exports/` 下的新目录，每次运行都创建独立目录，不能覆盖已有导出：

```powershell
& 'D:\PYTHON313\python.exe' image-eval-review/audit_annotations.py
```

只复验本次导出，无需读取当前人工库或请求模型：

```powershell
& 'D:\PYTHON313\python.exe' image-eval-review/audit_annotations.py --verify-export image-eval-review/private/annotation_exports/e02_20261109T105107_9fd48405
```

`--db` 可以选择已有数据库，缺失时拒绝而非创建空库；`--output` 可以指定尚不存在的目录，但必须位于本机 `private/` 下。核验失败返回退出码 1。导出期间若人工库、规则或图片变化，拒绝完成；保留未完成目录以供排查，重新运行使用新目录。不要把目录存在或某个 JSON 的状态字段单独当作成功依据，必须使用复验命令。
