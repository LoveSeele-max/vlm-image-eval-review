- [依赖说明](../../image-eval-review/requirements.txt)：本机使用 Python 3.13.7、Pillow 12.2.0；接口配置窗口仍只依赖标准库。

在仓库根目录复现：

```powershell
python image-eval-review/inspect_images.py
python -m unittest discover -s image-eval-review/tests -p test_inspect_images.py -v
```

第一条命令会重新检查本机原图，并覆盖仓库内两份检查数据文件；不会修改源图片。其他电脑需要具备来源清单中的实际素材路径，单独克隆代码不会获得原图。

新增 5 项测试均通过：正常文件哈希与只读性、错误路径与非图文件拒收、截断 JPEG 完整解码失败、EXIF 方向及多帧检查、重复汇总与失败保留。未把原图、EXIF 私人信息或模型原始响应提交到仓库。
