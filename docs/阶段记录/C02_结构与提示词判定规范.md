## 结构完整性：4 项

| ID | 核对对象 | 明确异常 | 允许的表现及证据不足 |
| --- | --- | --- | --- |
| structure_limb_connections | 肢体数量、归属和连接 | 多余或重复手脚、错误位置长出肢体、可确认的非设计性断裂或缺失 | 允许屈曲、交叉、玩具关节及简化手指；遮挡或裁切使关键连接不可见时记不可判断 |
| structure_head_face_connections | 头面五官及可见耳连接 | 重复五官、耳与眼或脸部穿插、明显错误融合 | 允许大头大眼及头顶长耳与脸侧小耳并存；模糊时不猜测异常 |
| structure_body_accessory_connections | 身体、服装和实际出现的配件连接 | 身体与衣物错误融成块状、配件穿过身体等明确矛盾 | 允许贴身衣服、手握物品和草帽贴背；没出现草帽不凭空增加配件要求 |
| structure_subject_scene_separation | 主体与实际底座、支撑面和背景交界 | 脚与背景错误融合、背景物体延伸成肢体、明显非设计性穿插 | 允许脚固定在玩具底座、接触阴影、正常遮挡及任意桌面材质；没底座本身不是结构异常 |

4 项适用于当前样本。`pass` 要求相关结构足够清楚且符合该项规则；`fail` 需要明确异常证据；无法完成关键部位核对且没有明确反例时为 `unjudgeable`。只能看到部分正常区域不能证明被遮住部分也正常。没有配件或底座时检查实际可见连接，不对不存在的部件虚构观察结果。

缺少目标长耳、服装或草帽，按 C01 主体特征或适用的提示词要求判定；只有额外存在明确的数量、连接或融合异常时，才在结构维度另记问题。不能把主体不像重复解释为结构异常，也不按普通人体耳数否决参考主体的玩具设计。

## 提示词要求：保留的 14 种边界

每种要求只发给原文明确包含它的样本。原文没有要求的内容不追加；`zqv` 仅保留为触发词，不变成视觉条目。完整的逐项通过、不符、不可判断规则见 [evaluation_spec.draft.json](../../image-eval-review/data/evaluation_spec.draft.json)。

| 要求 ID | 通过所需的可见证据 | 不能额外要求的内容 |
| --- | --- | --- |
| photo_style | 照片风格的立体物件、光照材质和空间表现 | 不验证真实相机拍摄；写实渲染可满足照片风格 |
| figurine | 独立展示的立体手办或模型人偶外观 | 不要求指定角色身份或真实物理尺寸 |
| collectible_toy | 小型展示玩具的造型与材质外观 | 不推断真实厘米尺寸、价格、品牌或收藏价值 |
| black_spiky_hair | 黑色或受光的深色头发，具有尖状发束 | 不逐根对应参考发束；允许正常高光 |
| long_upright_tan_ears | 两根长而整体直立的浅棕色耳朵 | 不追加原文未明确要求的内耳精确颜色 |
| rabbit_ear_placement | 两根高的浅棕兔耳，从头顶黑发后方伸出 | 不复制参考姿态或精确比例 |
| dark_inner_ears | 内耳有可区分于外围和阴影的明确深色区域 | 不规定 RGB 值或色块面积 |
| separate_face_ears | 头顶兔耳与脸侧小圆耳是分开的结构 | 不给其他提示词额外添加小圆耳要求 |
| light_tan_skin | 自然浅棕、浅暖肤色，光照允许可靠观察 | 不推断族群；不使用未经验证的精确色值阈值 |
| large_anime_eyes | 相对面部偏大的动漫风格眼睛 | 不要求特定眼色、视线或高光 |
| red_jacket | 红色外套，颜色及服装形态均可辨 | 不规定扣子与衣褶细节 |
| blue_shorts | 蓝色且为短裤形态 | 不追加白色裤脚要求 |
| sandals | 开放式鞋面、绑带或露趾等可识别的凉鞋结构 | 不规定绑带精确数量、颜色；脚被裁掉不等于没穿 |
| round_gold_base | 金色及圆形展示底座均有充分证据 | 不追加钱币浮雕、白色转盘或特定文字 |

属性组合按一致方式处理：全部属性有证据才 `pass`，任一属性明确矛盾则 `fail`；没有矛盾但所需证据不全则 `unjudgeable`。例如只看到一块金色、不能确认底座形状时，不能直接通过圆形金色底座项。

服装类型、肤色、照片风格和玩具外观目前是文字判定锚点，不声称已量化标定。C04 冻结前如仍有歧义，依据定义与参考输入核对，不按保留集结果调标准。`figurine` 与 `collectible_toy` 存在语义重叠，后续报告不能把条目数量视为独立样本数量。
